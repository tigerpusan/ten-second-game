# 10초 맞추기

카페·일반 매장에서 바로 사용할 수 있는 간단한 10초 맞추기 게임입니다.

## 게임 규칙
- START 버튼을 누르면 카운트 시작
- 다시 누르면 정지
- 9.97 ~ 10.02초 사이면 성공
- 정확히 10.00초면 PERFECT
- 우측 상단 ⚙ 설정에서 제목/성공범위/PERFECT 시간을 변경할 수 있습니다.

## 실행
`www/index.html`을 크롬에서 열면 바로 실행됩니다.

## Android APK 자동 빌드
GitHub Actions의 `Build Android APK` 워크플로가 자동으로 디버그 APK를 생성합니다.
